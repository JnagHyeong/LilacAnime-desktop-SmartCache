# LilacAnime_SmartCache 기능 구현 상세 리뷰

이번에 작업한 전체적인 기능 추가 및 상세 개선 내역은 아래와 같습니다.

---

## 🛠️ 기능 추가 및 개선 상세 내역

### 1. 스마트 메모리 비디오 캐싱 시스템 (스마트 캐시)
작품 재생 시 비디오 데이터를 메모리에 캐싱하여 네트워크 재요청을 줄이고 즉시 재생을 지원하도록 구현했습니다.
* **`videoCache` Map 구현**: 회차별 `.ts` 조각 및 `Blob` 데이터를 안전하게 관리합니다.
* **기기별 맞춤 용량 제한 (OOM 방지)**: 
  * 모바일 기기 감지 로직을 통해 탭 크래시(Out Of Memory)를 방지합니다.
  * **PC**: 최대 글로벌 캐싱 450MB, 한 회차당 150MB 한도 적용
  * **모바일**: 최대 글로벌 캐싱 200MB, 한 회차당 70MB 한도 차등 적용
* **자동 메모리 정리**: 
  * 글로벌 용량 초과 시 현재 시청 중인 회차를 보호하고, 가장 오래된 회차의 캐시를 우선 정리합니다.
  * 재생이 진행됨에 따라 전전 회차($N-2$) 데이터는 자동 삭제하여 메모리 누수를 원천 차단합니다.

---

### 2. 다음화 사전 캐싱 (Prefetching)
현재 재생 중인 영상의 진척도가 60%를 넘어갈 경우, 사용자 동선 끊김 없이 다음 회차를 미리 캐싱합니다.
* **자동 트리거 조건 (`fetchNextEpisodeData`)**: 현재 회차 재생률이 60% 이상이고 다음 화가 존재할 경우 작동합니다.
* **백그라운드 처리**: 백그라운드에서 다음 화의 HLS 주소(`.m3u8`) 분석 및 세그먼트 다운로드를 자동으로 수행하여, 다음 화 재생 시 로딩 대기 시간 없이 거의 즉시 재생이 가능하도록 구현했습니다.

---

### 3. MSE 기반 부분 캐시 및 전체 타임라인 보정
150MB 등 일부만 다운로드된 캐시 데이터도 완벽하게 재생하면서 타임라인이 깨지지 않도록 개선했습니다. (이 과정에서 캐싱 데이터와 스트리밍 데이터 간 불일치 문제를 해결했습니다.)
* **MSE 연동**: `MediaSource`와 `SourceBuffer`를 활용해 원시 바이너리(`.ts`)를 직접 비디오 엘리먼트에 주입합니다.
* **타임라인 보정**: `.m3u8` 파일의 `#EXTINF` 메타데이터를 파싱하여 전체 재생 시간을 정확하게 산출(`currentActiveDuration`)하고, 부분 캐시 상태에서도 타임라인 바가 전체 영상 길이를 올바르게 표시하도록 구현했습니다.

---

### 4. 캐시 범위를 벗어난 시킹 및 HLS 자연스러운 전환
사용자가 캐시되지 않은 뒷부분으로 점프할 때 발생할 수 있는 끊김 현상과 블랙스크린을 매끄럽게 처리했습니다.
* **동적 모드 전환**: 시킹 위치가 캐시 버퍼 범위를 벗어날 경우, 즉시 온라인 HLS 스트리밍 모드로 전환합니다.
* **부드러운 UX 처리 (`snapshotCanvas`)**: 
  * 전환 과정에서 화면 깜빡임이나 멈춤을 숨기기 위해 현재 프레임을 고해상도 `canvas`로 캡처하여 오버레이로 띄웁니다.
  * 온라인 스트리밍 `canplay` 이벤트 시점에 부드럽게 페이드아웃 및 제거하여 사용자 경험(UX)을 극대화했습니다.
